TradePro - Trade & Home Services HTML Template

Thank you for purchasing TradePro. This guide explains how to install, customise and launch your site. TradePro is plain HTML, CSS and vanilla JavaScript. There is no build step, no jQuery and no framework to learn.

Introduction

TradePro is designed for plumbers, electricians, builders, landscapers, cleaners and other local service businesses. It includes 13 pages, three home page variants, light and dark themes, and accessible components.

Preview photos are not included. The demo uses CSS and SVG placeholders only. No photographs or AI-generated images are in the download. Replace each placeholder with your own photography (see Images & placeholders).

Installation

  1. Unzip the download. Upload the contents of the tradepro folder to your web host (cPanel File Manager, FTP, Netlify, Cloudflare Pages, GitHub Pages and so on).
  2. Open index.html in a browser to check it works. You can also preview locally by double-clicking the file.
  3. Search and replace the placeholder details in every HTML file: phone (555) 012-3456 and +15550123456, email hello@yourdomain.com, the address and the company name.
  4. Edit page text directly in the HTML. Each page is standalone, so there is no template language to learn.
  5. Delete the pages and the documentation folder you do not need before going live.

The header, footer and sprite are repeated in each page. Use find-and-replace across files, or use a static site generator or server-side includes if you prefer partials.

Customising colours

All colours are CSS custom properties at the top of css/style.css (section 1). Change them once and the whole site updates.

:root{
  --accent:#0b63ce;        /* buttons, icons, highlights */
  --accent-strong:#084c9f; /* hover state */
  --accent-soft:#e6f0fc;   /* icon tiles, tinted backgrounds */
  --accent-text:#0b63ce;   /* accent used as text on white */
  --on-accent:#fff;        /* text on accent backgrounds */
  --navy:#0e1c2f;          /* hero, footer, dark sections */
}

Accent variants

Set data-accent on the <html> element to switch palettes. Two are included: electrician and builder. To add your own, copy one block in the stylesheet:

:root[data-accent="landscaper"]{
  --accent:#2f7d32; --accent-strong:#1f5c22; --accent-soft:#e5f3e6;
  --accent-text:#2f7d32; --on-accent:#fff; --navy:#10231a; --navy-2:#173626;
}

Check that --on-accent on --accent has a contrast ratio of at least 4.5:1, and that --accent-text on white does too. Light accents (yellow, amber) need dark text, as the electrician variant shows.

Dark mode

Dark mode is controlled by the data-theme attribute on <html> (light or dark). On first visit the visitor's system preference is used. The header toggle saves the choice in localStorage (key tradepro-theme). To force a theme, set data-theme="light" in the HTML and remove the theme lines from js/main.js (section "Theme"). Dark values are defined under :root[data-theme="dark"].

Fonts

TradePro uses Sora (headings) and Inter (body) from Google Fonts, loaded with a <link> in each page's head. Metric-adjusted local fallbacks ("Sora Fallback" and "Inter Fallback") prevent layout shift and keep the site readable if the font fails to load or you are offline.

Changing fonts

Update the Google Fonts link in each page and the two variables in css/style.css: --font-head and --font-body.

Self-hosting (recommended for GDPR)

Download the woff2 files (for example from google-webfonts-helper), place them in fonts/, remove the Google Fonts links and add:

@font-face{font-family:"Inter";src:url("../fonts/inter-var.woff2") format("woff2");font-weight:400 600;font-display:swap}
@font-face{font-family:"Sora";src:url("../fonts/sora-var.woff2") format("woff2");font-weight:600 800;font-display:swap}

Header & navigation

The sticky header contains the logo, navigation, phone number, quote button, dark mode toggle and mobile menu button. Dropdowns use CSS (:hover and :focus-within) so they work with keyboards. On screens up to 960px the menu becomes a full-screen panel; press Escape to close it. Mark the current page with aria-current="page". On phones a sticky "Call now" bar is shown (class .call-now); update its tel: link.

To use your own logo image, replace the contents of the .logo link with an <img> that has alt text.

Forms

Forms use HTML5 validation attributes (required, type="email", pattern, minlength) plus a small script that shows inline messages and moves focus to the first invalid field. Out of the box, forms do not send email; the demo shows a success message only. Connect one in either way:

Option A: form service (no server code)

Add a data-endpoint attribute with the URL from Formspree, Basin, Getform, Netlify Forms or similar. The script submits the form with fetch and shows the success or error message.

<form class="quote-card" data-form data-endpoint="https://formspree.io/f/your-id" novalidate>

Option B: your own PHP/Node handler

Point data-endpoint at your script, which should accept a POST and return a 2xx status. Validate and sanitise on the server; client-side checks are a convenience only.

Each form includes a hidden honeypot field named website. Discard any submission where it is filled in. Consider adding reCAPTCHA or Turnstile for additional protection.

Maps

The contact page has a map placeholder (.map-ph). Replace it with an embed iframe from Google Maps or OpenStreetMap and give it a title attribute, for example <iframe title="Map showing our location" loading="lazy" src="..."></iframe>. Add width:100%; min-height:380px; border:0; border-radius:20px in your CSS.

Images & placeholders

Placeholders are .ph elements (aspect ratio helpers: .ph--16x10, .ph--4x3, .ph--1x1, .ph--tall). To swap in a photo:

<img class="ph-img" src="images/team.jpg" alt="Our team on site" width="800" height="600" loading="lazy">

Use WebP or optimised JPEG, always supply width/height and meaningful alt text, and add .ph-img{width:100%;height:100%;object-fit:cover;border-radius:12px} to your CSS. Icons are an inline SVG sprite at the top of each page body (<use href="#i-name">). All icons were drawn for this template and are included under the same licence.

Browser support

Current versions of Chrome, Edge, Firefox and Safari (including iOS). Modern CSS (custom properties, color-mix(), :has(), grid) is used; very old browsers such as Internet Explorer are not supported. Layouts are tested from 360px to 1920px.
